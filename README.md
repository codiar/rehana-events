# قاعة ريحانة للمناسبات

موقع عربي متجاوب لقاعة ريحانة للمناسبات.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر المستودع على فرع `main`.
2. من Settings → Pages اختر `GitHub Actions` كمصدر للنشر.
3. راقب Actions حتى ينجح فحص TypeScript والبناء والنشر.

## تشغيل محلي

يتطلب Node.js 22 أو أحدث. نفّذ `npm install` ثم `npm run dev`.

## بيانات تحتاج تأكيدًا

- تم ترك البريد الإلكتروني ومعرّف التواصل الإضافي فارغين لأن بيانات المصدر كانت غير موثوقة/غير مكتملة.
- معاينة الخريطة مبنية على بحث العنوان النصي وليست دبوسًا جغرافيًا مؤكدًا. أكّد الموقع الدقيق مع إدارة القاعة قبل نشره كعنوان نهائي.
- حقوق كوديار تك نصية لتجنب استخدام شعار بديل غير مطابق؛ أضف ملف الشعار الرسمي عندما يكون متاحًا.
